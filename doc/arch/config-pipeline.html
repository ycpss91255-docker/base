1. 四檔結構

所有人工編輯的 Docker config 統一為 TOML。四個檔案，按服務邊界分割：

檔案擁有者關注點分層
setup.tomlrepo（已提交）Docker 基礎建設template -> repo -> caller-supplied (ADR-36)
setup.local.toml操作者（gitignored）每個 instance 的基礎建設覆蓋覆蓋 setup.toml
.env.tomlrepo（已提交）容器服務 runtime envtemplate -> repo
.env.local.toml操作者（gitignored）每個 instance 的服務 env覆蓋 .env.toml

2. 型別感知合併語意

TOML spec 不定義 merge。本專案的合併規則由型別決定，符合 6/8 業界系統的共識：

修正 ADR-25 sec.3：Section-replace 不再是全面性的。合併規則現在由型別決定。ADR-25 sec.3 的推理（ordered list 不能 key-merge）仍然正確，成為 array-replace 那一半的基礎。

7. TOML 結構：前後對照

Before: INI (.setup.conf) 現行

[project]
name = my-robot

[volumes]
mount_1 = ./src:/home/user/ws/src
mount_2 = ./data:/home/user/data
mount_3 = /dev/shm:/dev/shm

[gui]
mode = wayland

[devices]
device_1 = /dev/video0

[image]
rule_1 = jetson*:l4t

編號 key（mount_N、device_N、rule_N）編碼有序清單。無型別系統、無驗證。新增/移除時需手動重新編號。

After: TOML (setup.toml) ADR-37

[project]
name = "my-robot"

[[volumes]]
source = "./src"
target = "/home/user/ws/src"
mode = "rw"

[[volumes]]
source = "./data"
target = "/home/user/data"

[[volumes]]
source = "/dev/shm"
target = "/dev/shm"

[gui]
mode = "wayland"

[[devices]]
path = "/dev/video0"

[[image.rules]]
pattern = "jetson*"
tag = "l4t"

[[array of tables]] 取代編號 key。有型別欄位。可用 IDE 工具 + schema 驗證。

.env.toml（服務 runtime）

Before: .env.local 現行

ROS_DOMAIN_ID=42
ROS_MASTER_URI=http://192.168.1.10:11311
LOG_LEVEL=debug
WATCHDOG_ENABLED=1

扁平 KEY=VALUE。無型別、無註解、無結構。

After: .env.toml ADR-37

[ros]
domain_id = 42
master_uri = "http://192.168.1.10:11311"

[logging]
level = "debug"

[watchdog]
enabled = true

有型別值（int、string、bool）。按關注點分組。允許註解。覆蓋層 key-level merge。
